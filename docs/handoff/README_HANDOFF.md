# Family Scheduling OS — Codex Handoff

## Mission

Build a production-ready, AI-assisted **Family Scheduling OS** that behaves like one polished app containing multiple specialized scheduling mini-apps.

This is not a static mockup and not a toy calendar.

The system must include:
- Real frontend
- Real backend
- Persistent database
- Authentication
- Household/member permissions
- AI-assisted scheduling
- Deterministic conflict detection
- Employee scheduling
- Shia Baby business mini-app
- Shopping reminders
- General reminders
- Errands
- Appointments
- School
- Practice
- Competitions
- Games
- Hubby Work
- Unified All Schedules calendar
- Mobile, iPad/tablet, and desktop responsive design
- Production-quality testing and security

## Critical Build Requirement

Codex must operate as the **lead orchestrator** over a swarm of specialized agents working in a **dynamic parallel workflow**.

Do not let every agent independently invent shared schemas or contracts.

### Order of operation

1. Inspect repo.
2. Freeze shared contracts.
3. Freeze core data model.
4. Freeze permissions.
5. Freeze API/action contracts.
6. Split independent work across agents.
7. Merge through integration gates.
8. Continuously run tests.
9. Resolve conflicts centrally.
10. Deliver a working product, not just planning documents.

## Build philosophy

**Build Deep, Run Flat.**

Internally:
- sophisticated architecture
- strict contracts
- deterministic state
- strong validation
- modular services
- auditability

Externally:
- simple
- elegant
- uncluttered
- natural language input
- easy for a family to use every day

## Execution instruction for Codex

Start implementation after the core contracts are frozen.

Do not stop after writing plans.

At every meaningful checkpoint report:
- completed
- in progress
- tests
- blockers
- next milestone
- approximate completion percentage
