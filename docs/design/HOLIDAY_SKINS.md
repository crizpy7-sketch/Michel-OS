# Holiday / Seasonal Skins

Implemented through `public/lib/theme.js` + CSS `data-skin` attributes.

## Modes

- `auto`
- `classic`
- `christmas`
- `halloween`
- `valentines`
- `spring`

Automatic windows:

- December → Christmas
- October → Halloween
- Feb 1–14 → Valentine's
- Mar 15–Apr 30 → Spring/Easter
- otherwise Classic

Skins can change background atmosphere, accent tint, decorative glints, and subtle motion. They cannot change layout, content hierarchy, icon identity, or any engine behavior.
